# Software Engineering for Data Scientists

A practical guide to writing reliable, maintainable, testable, and production-ready data science code.

This repository was created as a study and reference project inspired by
*Software Engineering for Data Scientists* by Catherine Nelson.

It combines:
- personal study notes
- software engineering best practices
- practical Python examples
- data science-specific patterns
- checklists and templates
- lessons learned from real-world projects

> This repository is not a reproduction or replacement for the book.
> It is a practical guide built from study notes, original examples, and complementary best practices.
